# Forgot Password

The Forgot Password feature allows users to request a password reset if they can no longer remember their account password. It provides a secure way to regain access without contacting system administrators.

## Scenarios

- **Success Scenarios**
  - [1.5.S1. User can request password reset successfully.](./scenarios/s1/)
- **Failure Scenarios**
  - [1.5.F1. Password reset request fails when required fields are empty.](./scenarios/f1/)
  - [1.5.F2. Password reset request fails when email is not found.](./scenarios/f2/)
