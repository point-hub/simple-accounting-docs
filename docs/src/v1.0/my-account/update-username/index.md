# Update Username

The Update Username page allows users to change their display name or username within the application. This ensures that user profile information remains accurate and up to date.

The username may be displayed in the dashboard, reports, activity logs, or audit trails.

- **Success Scenarios**
  - [2.1.S1. User can update username successfully.](./scenarios/s1/)
- **Failure Scenarios**

  - [2.1.F2. Username update fails when required fields are empty.](./scenarios/f2/)
